Konekt gives your app an [EIP-1193](https://eips.ethereum.org/EIPS/eip-1193)-compatible provider backed by WalletConnect v2. It has no `@walletconnect` runtime dependency, and chain support is split into optional imports so unused code can stay out of your bundle.

## A smaller, clearer connection layer

<CardGrid>
  <Card title="About 90% smaller" icon="open-book">
    The modern-browser EVM path is **14.53 kB** through the first encrypted message. The official `@walletconnect/ethereum-provider@2.23.10` main bundle is **142.97 kB**, minified and gzipped.
  </Card>
  <Card title="No runtime framework tax" icon="puzzle">
    Konekt has no `@walletconnect` runtime dependency. Add chain adapters, reads, authentication, and UI only when your app uses them.
  </Card>
  <Card title="Your stack stays in charge" icon="setting">
    Keep viem, wagmi, ethers, your RPCs, and your design system. Konekt owns WalletConnect sessions and requests—not the rest of your application.
  </Card>
</CardGrid>

[See the versioned measurements and full Reown comparison →](./guides/why-konekt/)

<CardGrid stagger>
  <Card title="Start with one provider" icon="rocket">
    Call `Provider.init()` once, show the pairing QR, and wait for the user to approve the connection in their wallet.
  </Card>
  <Card title="Choose your networks" icon="puzzle">
    Add EVM, Solana, Bitcoin, or Cosmos networks. Konekt proposes only the networks and wallet methods you configure.
  </Card>
  <Card title="Bring your own UI—or use ours" icon="setting">
    Listen for a pairing URI and render it yourself, or install `konekt-ui` for a React wallet picker and QR modal.
  </Card>
  <Card title="Add sign-in when you need it" icon="document">
    The optional SIWE feature requests authentication during pairing. Verify the signed result on your server.
  </Card>
</CardGrid>

## Where to begin

- New to konekt? Follow [Getting started](./guides/getting-started/) for a complete first connection.
- Want to see it running first? Open the [live showcase](./showcase/): pairing, every EIP-1193 method, kernel reads, and the event log.
- Already using `@walletconnect/ethereum-provider`? Follow the [migration guide](./guides/migrate-ethereum-provider/).
- Comparing clients? See [why Konekt is better](./guides/why-konekt/) for versioned bundle measurements and architecture trade-offs.
- Need more than Ethereum? Read [Chains and networks](./guides/chains/).
- Building a connect button or wallet picker? Choose between [wallet events](./guides/wallet-ui/) and [konekt-ui](./guides/konekt-ui/).
- Using an EVM client library? Follow the [viem](./guides/viem/), [ethers](./guides/ethers/), or [wagmi](./guides/wagmi/) integration guide.
- Using Solana, Bitcoin, or Cosmos? Follow the [Solana](./guides/solana/), [Bitcoin](./guides/bitcoin/), or [CosmJS](./guides/cosmjs/) guide.
- Using Next.js or another server-rendered framework? Read [Frameworks and SSR](./guides/frameworks/).
- Configuring storage, timeouts, or diagnostics? Read [Sessions and options](./guides/sessions/).
- Keeping the initial page small? See the measured [bundle sizes, tree-shaking, and lazy-loading patterns](./guides/bundle-size/).
- Adding Sign-In with Ethereum? Read [Authentication features](./guides/features/).
- Something not working? Check [Troubleshooting](./guides/troubleshooting/) for every error Konekt throws.
- Looking up a type or function? Open the [API reference](./api/readme/).
